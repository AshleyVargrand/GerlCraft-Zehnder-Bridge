Zehnder ComfoAir Bridge

Installer fuer M5Stack AtomS3 Lite

Firmware installieren

Version 1.1.0

Installiert die Zehnder ComfoAir Bridge auf einem M5Stack AtomS3 Lite. WLAN, MQTT und Geraetename werden anschliessend ohne erneutes Kompilieren ueber das Setup-WLAN eingerichtet.

Bitte diese Seite mit Google Chrome oder Microsoft Edge auf einem Computer oeffnen. Der Browser darf nicht auf den seriellen Anschluss zugreifen. Bitte die Seite ueber HTTPS oeffnen.

Den AtomS3 waehrend der Installation von der Zehnder-Anlage und vom ComfoNet trennen.

Home Assistant Dashboard

Fertige Uebersicht mit Temperaturen, Luftstroemen, Rueckgewinnung, Energie, Filterstatus und Verlauf. Das Paket enthaelt ausserdem die eigene responsive GerlCraft-Anlagenkarte mit animierten Luftstroemen fuer vorhandene Dashboards.

Dashboard-Paket herunterladen SHA-256

Vor der Installation

  1. Chrome oder Edge auf einem Computer verwenden.
  2. Den AtomS3 mit einem USB-C-Datenkabel anschliessen.
  3. Serielle Monitore und PlatformIO vorher schliessen.
  4. Falls die Verbindung scheitert: Taste etwa zwei Sekunden halten, bis die interne LED gruen leuchtet, dann erneut installieren.

Nach der Installation

  1. Den AtomS3 neu starten.
  2. Mit dem WLAN Zehnder-Bridge-Setup verbinden.
  3. Das WLAN-Passwort zehnder-setup verwenden.
  4. http://192.168.4.1 im Browser oeffnen.
  5. WLAN, MQTT und ein eigenes Admin-Passwort eintragen.
